Abstract
========

This PEP proposes to add a means for users to safely and efficiently
share arbitrary objects (or at least their data) between multiple
interpreters in the same process.  This would be an improvement over
the basic and inefficient data sharing that currently exists.  The
proposed solution involves three parts: add C-API, add a new
``PyTypeObject`` slot, and add a new Python object special method.


Motivation
==========

The main deficiency for people using multiple interpreters is with
efficiency.  The main area of inefficiency is communication between
interpreters and otherwise sharing data between them.  Improving
efficiency there would have a meaningful impact on the usability
of multiple interpreters.


Specification
=============

concurrent.interpreters
-----------------------

We will add the following function to the
:mod:`concurrent.interpreters` module:

* ``as_shareable(obj) -> CrossInterpreterObjectData``
  Convert the given object to raw cross-interpreter data.  Return an

  typedef struct _xidata _PyXIData_t;
  typedef PyObject *(*xid_newobjfunc)(_PyXIData_t *);
  typedef void (*xid_freefunc)(void *);

  #define _PyXIData_DATA(DATA) ((DATA)->data)
  #define _PyXIData_OBJ(DATA) ((DATA)->obj)
  #define _PyXIData_INTERPID(DATA) ((DATA)->interpid)

  #define _PyXIData_SET_FREE(DATA, FUNC) \
      do { \
          (DATA)->free = (FUNC); \
      } while (0)
  #define _PyXIData_CHECK_FREE(DATA, FUNC) \
      ((DATA)->free == (FUNC))

  #define _PyXIData_SET_NEW_OBJECT(DATA, FUNC) \
      do { \
          (DATA)->new_object = (FUNC); \
      } while (0)
  #define _PyXIData_CHECK_NEW_OBJECT(DATA, FUNC) \
      ((DATA)->new_object == (FUNC))

  typedef int xidata_fallback_t;
  #define _PyXIDATA_XIDATA_ONLY (0)
  #define _PyXIDATA_FULL_FALLBACK (1)

  typedef int (*xidatafunc)(PyThreadState *, PyObject *, _PyXIData_t *);
  typedef int (*xidatafbfunc)(
          PyThreadState *, PyObject *, xidata_fallback_t, _PyXIData_t *);
  typedef struct {
      xidatafunc basic;
      xidatafbfunc fallback;
  } _PyXIData_getdata_t;

  typedef int (*xid_wrapfunc)(PyThreadState *, PyObject *,
                              PyObject **, _PyXIData_unwrapper_t*);
  typedef PyObject *(*xid_unwrapfunc)(PyThreadState *, void *, PyObject *);
  typedef struct _xidata_unwrapper {
      xid_unwrapfunc func;
      void *data;
      xid_freefunc free;
  } _PyXIData_unwrapper_t;
  typedef struct {
      // The _PyXIData_t fields that are swapped out for an unwrapper:
      void *data;
      xid_newobjfunc new_object;
      xid_freefunc free;
  } _PyXIData_wrapped_orig_t;
